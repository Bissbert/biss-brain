## 1. Schema Migrations

Migration version: `migration_v05`. Applied at startup in
`scripts/common.py:_ensure_schema()` using `ALTER TABLE ... ADD COLUMN ...`
guarded by `PRAGMA table_info` checks (so re-runs are idempotent).

### 1.1 New columns on `chunks` (SQLite, every project DB)

| Column | Type | Default | Purpose |
|---|---|---|---|
| `salience` | `INTEGER` | `5` | 1–10 score set at flush; gates replay weight & promotion |
| `labile_until` | `INTEGER` | `0` | Unix timestamp; reconsolidation merge gate |
| `reconsolidation_count` | `INTEGER` | `0` | Increments on each merge; ≥ 5 promotes to `kind=lesson` |
| `co_retrieval_count` | `INTEGER` | `0` | (Aggregated; per-pair counts live in `edge_bumps`) |
| `cross_links` | `TEXT` | `'[]'` | JSON list of cross-project typed links — never aliases `related_ids` |
| `cross_eligible` | `INTEGER` | `0` | 0/1; gates promotion to `_global` |
| `retrieval_count_local` | `INTEGER` | `0` | Per-project retrieval count (R3 mitigation: replaces global `retrieval_count` for cross-project hits) |

The existing `retrieval_count` column stays for legacy code paths;
cross-project hits bump only `retrieval_count_local`.

### 1.2 New table `edge_bumps` (SQLite, per-project)

```sql
CREATE TABLE IF NOT EXISTS edge_bumps (
    id          INTEGER PRIMARY KEY,
    session_id  TEXT NOT NULL,
    id_a        TEXT NOT NULL,
    id_b        TEXT NOT NULL,
    ts          INTEGER NOT NULL,
    drained     INTEGER NOT NULL DEFAULT 0
);
CREATE INDEX idx_edge_bumps_undrained ON edge_bumps(drained, ts);
CREATE INDEX idx_edge_bumps_pair ON edge_bumps(id_a, id_b);
```

`(id_a, id_b)` is canonicalised lexicographically at insert time so
`(A,B)` and `(B,A)` collapse.

### 1.3 New typed `related_ids` shape

Old shape (legacy):

```json
["chunk-id-1", "chunk-id-2"]
```

New shape:

```json
[
  {"id": "chunk-id-1", "type": "co_occurs", "weight": 0.42, "ts": 1714492800},
  {"id": "chunk-id-2", "type": "refines", "weight": 0.78, "ts": 1714493000}
]
```

`type ∈ {refines, contradicts, generalises, instance_of, caused, co_occurs}`.

**Read adapter (`scripts/common.py`):**

```python
def parse_related_ids(raw: str) -> list[dict]:
    """Tolerant parser: returns list of dicts. Accepts old or new shape."""
    if not raw:
        return []
    data = json.loads(raw)
    if not data:
        return []
    if isinstance(data[0], str):
        return [{"id": x, "type": "co_occurs", "weight": 0.5, "ts": 0}
                for x in data]
    return data
```

Writers always emit the new shape. Read paths always go through
`parse_related_ids`.

### 1.4 New `_global` project directory

Path: `~/.claude/brain/_global/`.

Contains:

- `meta.sqlite` (same chunks schema as a project DB)
- `lancedb/` (same vector table layout)
- `project_path.txt` containing the literal string `__global__`

The 12-hex hash of `__global__` is reserved (`scripts/common.py` exports
`GLOBAL_PROJECT_HASH = "5da0e6b1ad8a"` — actually computed as
`sha256("__global__")[:12]`; pin in code at first init).

## 3. Per-Stream Specs

### 3.1 Capture team

**Files:** `scripts/flush.py`, `scripts/common.py`.

**Salience scoring (heuristic, default).** Computed at flush, before insert.

```python
def compute_salience(text: str, recent_embeddings: list[np.ndarray],
                     embedding: np.ndarray, cfg: dict) -> int:
    length_norm = min(len(text) / 2000.0, 1.0)
    if recent_embeddings:
        sims = [cosine(embedding, e) for e in recent_embeddings]
        novelty = 1.0 - max(sims)
    else:
        novelty = 1.0
    raw = (cfg["length_weight"] * length_norm
           + cfg["novelty_weight"] * novelty)
    return max(1, min(10, int(round(raw * 10))))
```

`recent_embeddings` is the last 20 chunks in the same session, fetched via
existing LanceDB query.

**Salience scoring (LLM v2, opt-in).** When `capture.salience.use_llm=true`:
single Haiku call with prompt `prompts/score_salience.md` returning an
integer 1–10. Falls back to heuristic on parse failure.

**Schema migration.** `scripts/common.py:_ensure_schema` adds the seven
columns from §1.1 idempotently.

```python
def _stage_nrem2_edge_drain(pdir, cfg):
    cur = sqlite.execute(
      "SELECT id_a, id_b, COUNT(*) FROM edge_bumps "
      "WHERE drained=0 GROUP BY id_a, id_b "
      "HAVING COUNT(*) >= ?",
      (cfg["stdp"]["co_retrieval_min_count"],)
    )
    for id_a, id_b, count in cur:
        weight = min(1.0, count / 10.0)
        _add_typed_edge(pdir, id_a, id_b, type="co_occurs", weight=weight)
        sqlite.execute("UPDATE edge_bumps SET drained=1 "
                       "WHERE id_a=? AND id_b=?", (id_a, id_b))
```

`_add_typed_edge` reads the existing `related_ids` for both chunks via
`parse_related_ids`, upserts the typed entry, and writes back.

### 3.3 Recall team

**Files:** `scripts/recall.py`, `scripts/inject_context.py`,
`mcp/server.py`.

**STDP enqueue.** After collecting result IDs in a recall:

```python
def _enqueue_co_retrievals(meta, session_id, result_ids):
    pairs = [(min(a,b), max(a,b))
             for i,a in enumerate(result_ids)
             for b in result_ids[i+1:]]
    now = int(time.time())
    meta.executemany(
      "INSERT INTO edge_bumps(session_id, id_a, id_b, ts) VALUES(?,?,?,?)",
      [(session_id, a, b, now) for a,b in pairs]
    )
```

Called once per recall response.

**RIF.** After retrieving chunk A, find chunks sharing ≥ 3 of A's top-10
dense neighbours; multiply their `decay_score` by 0.98.

```python
def _apply_rif(meta, tbl, retrieved_id, retrieved_vec, cfg):
    a_nbrs = set(_top_k_neighbours(tbl, retrieved_vec, k=10,
                                    exclude_id=retrieved_id))
    for nbr_id in a_nbrs:
        nbr_vec = _get_vec(tbl, nbr_id)
        nbr_nbrs = set(_top_k_neighbours(tbl, nbr_vec, k=10,
                                          exclude_id=nbr_id))
        if len(a_nbrs & nbr_nbrs) >= cfg["rif"]["shared_neighbour_threshold"]:
            meta.execute(
              "UPDATE chunks SET decay_score = decay_score * ? WHERE id = ?",
              (cfg["rif"]["decay_multiplier"], nbr_id)
            )
```

Called for each retrieved chunk. Run per-project — never apply RIF using
cross-project neighbours.

**Labile window.** Recall stamps every returned chunk:

```python
meta.execute("UPDATE chunks SET labile_until = ? WHERE id IN (?,?,...)",
             (int(time.time()) + cfg["reconsolidation"]["labile_window_seconds"],
              *result_ids))
```

### 3.4 Reconsolidation team

**Files:** `scripts/flush.py`.

**Pre-insert merge check.** Before the existing hash dedup:

```python
def _try_reconsolidate(pdir, tbl, meta, new_text, new_vec, cfg):
    if not cfg["reconsolidation"]["enabled"]:
        return None
    now = int(time.time())
    cur = meta.execute(
      "SELECT id, text FROM chunks WHERE labile_until > ? AND superseded_by = ''",
      (now,)
    )
    candidates = list(cur)
    if not candidates:
        return None
    for cid, ctext in candidates:
        cvec = _get_vec(tbl, cid)
        if cosine(new_vec, cvec) >= cfg["reconsolidation"]["merge_cosine_threshold"]:
            merged = _llm_merge(new_text, ctext)  # prompts/reconsolidate_merge.md
            new_count = _bump_recon_count(meta, cid)
            if new_count >= cfg["reconsolidation"]["promote_to_lesson_after"]:
                meta.execute("UPDATE chunks SET kind='lesson', "
                             "consolidation_round=2 WHERE id=?", (cid,))
            _update_chunk_text(pdir, tbl, meta, cid, merged)
            return cid
    return None
```

If `_try_reconsolidate` returns a non-None ID, the new chunk is **not**
inserted; the existing chunk is updated in place.

```
distinct fact. Tighten language. Do not invent.

{existing_text}

NEW:
{new_text}

Output the merged chunk only.
```

is a conservative-by-default choice — admits fewer chunks, never more.

**Cross-project recall.** When `cross_project.enabled=true`:

```python
def search_cross_project(query_vec, cfg):
    gtbl = _open_global_lance()
    results = gtbl.search(query_vec).limit(cfg["recall.top_k_global"]).to_list()
```

```python
def _write_cross_link(meta, src_id, dst_id, dst_project, type_, weight):
    raw = meta.execute("SELECT cross_links FROM chunks WHERE id=?", (src_id,)).fetchone()[0]
    links = json.loads(raw or "[]")
    links.append({"id": dst_id, "project": dst_project, "type": type_, "weight": weight})
    meta.execute("UPDATE chunks SET cross_links=? WHERE id=?",
```

## 5. Test Surface

Every team produces unit tests in `tests/test_<stream>.py`. The phase exit
criterion requires the full suite green plus three integration tests that
cross stream boundaries:

- `test_flow_capture_through_recall`: captures → flushes → recalls → asserts
  STDP queue populated, salience set, labile_until set.
- `test_flow_recall_to_reconsolidation`: recalls → captures within labile
  window → asserts merge happened, no new chunk inserted.
- `test_flow_global_admission`: pin a chunk, run dream pass with
  cross_project.enabled, assert promotion to `_global`, assert
  cross-project recall returns it with source label.
