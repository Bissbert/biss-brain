# Neuroscience of Memory: A Literature-Anchored Map

> Reference for the v2 architecture. The implementation is bio-inspired, not bio-mimetic;
> this document records the source mechanisms so design decisions remain traceable to
> primary literature.

---

## 1. Complementary Learning Systems (CLS)

**Mechanism.** McClelland, McNaughton & O'Reilly (1995) formalised the observation that
a single connectionist network cannot simultaneously learn fast (single-shot, episodic)
and slow (statistical, generalised) — the catastrophic interference problem. Fast
learning that overwrites existing weights destroys prior knowledge; slow interleaved
learning cannot bind specific episodes. The brain solves this with two distinct systems
with different learning rates and representational geometries.

The hippocampus uses sparse, orthogonal (pattern-separated) representations to bind
arbitrary conjunctions of features quickly — one or a few exposures. The neocortex uses
dense, overlapping, distributed representations that change slowly via interleaved
replays, accumulating statistical regularities across many episodes into semantic
knowledge. Consolidation is the process of hippocampal traces repeatedly reactivating
neocortical weights in small steps until a stable neocortical representation forms.

**Computational role.** The hippocampus solves the fast-binding / low-interference
problem; the neocortex solves the generalisation / schema-extraction problem. Two
systems exist because no single architecture can optimise both simultaneously — the
learning rate required for one destroys the other.

**2016 update (Kumaran, Hassabis & McClelland, *Trends in Cognitive Sciences*).**
Expands the theory in two directions: (a) hippocampal replay is not just a consolidation
mechanism but can be goal-weighted — the system replays experiences preferentially based
on reward and salience; (b) neocortical learning can be rapid for schema-consistent
information (see §5), softening the strict slow-neocortex assumption.

**Key papers**

- McClelland, McNaughton & O'Reilly (1995), *Psychological Review* 102(3)
- Kumaran, Hassabis & McClelland (2016), *Trends in Cognitive Sciences* 20(7):512–534

## 2. Hippocampal Subfields: Pattern Separation vs. Pattern Completion

### Dentate Gyrus (DG)

Receives input from entorhinal cortex (EC) via the perforant path. Granule cells
(~1 million in rodents) vastly outnumber EC layer II cells, creating a divergent
expansion. Only ~2–4% of granule cells are active at any time — extreme sparsity.
Mossy fibre projections to CA3 are sparse and powerful: each CA3 pyramidal cell receives
input from only 3–4 granule cells, making each DG activation a strong, specific
"teaching signal." The result is that similar EC inputs map to orthogonal DG/CA3
representations — **pattern separation**.

### CA3

Contains ~300,000 pyramidal cells with massive recurrent collaterals (~12,000 recurrent
synapses per cell in rodents). This autoassociative architecture implements attractor
dynamics: a partial input cue drives the network toward the stored attractor state,
completing the pattern from incomplete input — **pattern completion** (Rolls & Kesner,
2006). CA3 is the locus of one-shot associative binding.

### CA1

The output gate. Receives both the Schaffer collateral output of CA3 and direct EC
input (layer III), making it a comparator between what CA3 predicts (stored memory) and
what EC reports (current input). CA1 projects to subiculum and back to EC to complete
the loop.

**Computational role.** DG enforces novelty by orthogonalising similar inputs
(preventing interference). CA3 enables retrieval from partial cues (robustness to
noise). CA1 integrates and gates output.

**Key paper**: Yassa & Stark (2011), *Trends in Neurosciences* 34(10):515–525.
DOI 10.1016/j.tins.2011.06.006.

## 3. Sleep-Dependent Memory Consolidation

### NREM / Slow-Wave Sleep

Three oscillations couple hierarchically:

1. **Slow oscillations (SO, ~0.75 Hz):** Cortical neurons alternate between a
   depolarised "up state" and a hyperpolarised "down state." The up state creates a
   window of excitability.
2. **Sleep spindles (12–16 Hz):** Generated by the thalamic reticular nucleus, spindles
   nest within SO up states. They open Ca²⁺ channels and facilitate synaptic tagging in
   cortical neurons.
3. **Sharp-wave ripples (SWRs, 80–200 Hz):** Hippocampal population bursts, lasting
   ~100 ms, carrying compressed replays of waking sequences. SWRs are timed to nest
   within spindle troughs, which nest within SO up states.

This **triple coupling** (SO → spindle → ripple) constitutes a precise communication
protocol: the SO gates cortical excitability; the spindle relays hippocampal replay
content to neocortical targets and primes them for LTP; the ripple delivers the
compressed memory trace.

Wilson & McNaughton (1994, *Science* 265) established that hippocampal cell assemblies
active during maze running re-activate in the same sequence during subsequent NREM
sleep — the founding replay demonstration.

### REM Sleep

Walker & Stickgold (2004, *Neuron* 44:121–133; 2006, *Annual Review of Psychology*
57:139–166) document distinct REM roles: (a) emotional memory consolidation — the
noradrenergic "safe" environment of REM (low NE) allows re-processing of emotional
episodic content without re-triggering the affective response; (b) procedural / motor
memory — evidence for offline motor sequence consolidation continuing into REM stages.

### Synaptic Homeostasis Hypothesis (SHY)

Tononi & Cirelli (2003, *Brain Research Bulletin*; 2014, *Neuron*) propose a distinct
function: waking plasticity causes net synaptic potentiation across the cortex
(unsustainable metabolically and informationally). Sleep, specifically NREM slow
oscillations, globally downscales synaptic weights — weakening low-salience connections
and renormalising the system for new learning.

**SHY vs. Replay: complementary, not competing.** Replay (active system consolidation)
selects which traces transfer to neocortex; SHY describes the complementary function of
pruning weak connections to prevent saturation and extract gist. The two operate at
different scales: replay is content-specific; SHY is a global gain-control mechanism.

## 4. Replay

Replay is the sequential reactivation of hippocampal place-cell (or episode-coding)
ensembles in temporal order, compressed ~20× relative to the original experience and
occurring during SWRs (~100 ms events). Place cells that fired in sequence over seconds
of navigation re-fire in the same sequence within a single ripple.

- **Reverse replay**: sequences fire in reverse temporal order, prominent after reward
  and at the end of trajectories; functionally proposed to link outcome to prior
  actions — a credit-assignment mechanism (Foster & Wilson, 2006, *Nature* 440:680–683;
  also documented in Diba & Buzsáki, 2007, *Nature Neuroscience* 10:1241–1242).
- **Forward replay**: sequences fire in the original temporal order, prominent before
  movement and during awake rest; functionally linked to predictive planning (Diba &
  Buzsáki, 2007, *Nature Neuroscience* 10:1241–1242 — same paper that documented
  forward and reverse replay during ripples).
- **Compression**: ~20× during SWRs; ~7–10× during theta sequences in active
  exploration. Compression ratio matters because it determines whether the timescale of
  hippocampal reactivation falls within the STDP induction window (~20–50 ms) for
  downstream neocortical synapses.

**Computational role.** Replay effectively performs gradient descent on episodic
experience offline, allowing the neocortex to integrate event statistics without
re-running the original experience. It is also now established as a planning mechanism:
future-oriented forward replay precedes decision points.

## 5. Schema Integration

Tse et al. (2007, *Science* 316:76–82, DOI 10.1126/science.1135935) trained rats on a
flavour-place association task until
a "schema" (structured prior knowledge of the environment) was established. New
flavour-place pairs consistent with the existing schema were consolidated into
neocortex within 24 hours — far faster than the months normally required for
hippocampal-independent consolidation. Critically, hippocampal lesions 48 hours
post-training did not impair schema-consistent memories, indicating rapid transfer.
New schema-inconsistent pairs showed normal slow consolidation.

**What is a schema mechanically?** Ghosh & Gilboa (2014, *Neuropsychologia* 53) define
schemas as structured neocortical representations that encode relational regularities
across episodes — essentially the "prior" over event structures. They are distributed
across medial prefrontal cortex (mPFC) and posterior neocortex. Schema-consistent new
information can be slotted directly into existing mPFC representational structure,
bypassing the slow interleaved replay process.

**Computational role.** Schemas function as a compression codec: if new information can
be expressed as a delta on an existing schema, the full-pattern transfer cost drops
dramatically. The hippocampus still mediates initial encoding and the first night of
consolidation, but the mPFC scaffold accelerates handoff.

## 6. Reconsolidation

Nader, Schafe & LeDoux (2000, *Nature* 406) showed that a consolidated fear memory
became protein-synthesis-dependent again upon retrieval. Infusing anisomycin (protein
synthesis inhibitor) into the amygdala immediately after memory reactivation abolished
the memory on next test, regardless of whether reactivation occurred 1 or 14 days
post-conditioning.

Mechanistically, retrieval triggers NMDA receptor activation → Ca²⁺ influx → AMPAR
internalisation → the synaptic trace becomes labile and requires new protein synthesis
(new AMPAR insertion, cytoskeletal remodelling) to re-stabilise.

**Computational role.** Every act of retrieval is a write operation, not a read. The
re-stabilisation process can incorporate new information, updating the trace. This is
the neural basis for memory modification, extinction, and (pathologically) false
memory formation. The prediction-error signal (surprise, novelty) appears to gate
whether destabilisation occurs — highly predicted content may be read without
labilisation.

## 7. Forgetting as an Active Mechanism

Three distinct mechanisms:

1. **Decay (passive)** — originally proposed as passive disuse-based fading. Now
   largely displaced by evidence for active mechanisms; "pure decay" has little
   empirical support.

2. **Interference** — earlier (proactive) or later (retroactive) memories interfere at
   retrieval. Distinct representations sharing retrieval cues compete. This is
   fundamentally an index/cue collision problem.

3. **Active forgetting via AMPAR removal** — Hardt, Nader & Nadel (2013, *Trends in
   Cognitive Sciences* 17(3):111–120, DOI 10.1016/j.tics.2013.01.001) propose that
   forgetting of long-term memories involves regulated endocytosis of GluA2-containing
   AMPA receptors from synapses. Blocking GluA2/AMPAR removal in the hippocampus during
   the retention interval prevents normal forgetting of object-location memories
   (Migues et al., 2016, *Journal of Neuroscience* 36(12):3481–3494, DOI
   10.1523/JNEUROSCI.3333-15.2016). This is a scheduled, enzyme-mediated synaptic
   weakening — the biological equivalent of a time-to-live with active deletion.

4. **Retrieval-induced forgetting (RIF)** — Anderson et al. demonstrated that
   retrieving a memory inhibits competing memories in the same category via prefrontal
   top-down suppression of hippocampal traces. A retrieval-specific active suppression
   mechanism, requiring lateral PFC.

**Why forgetting is adaptive.** It reduces interference between similar memories,
enables gist extraction (by removing specific episodic detail while retaining
statistical regularities), and prevents memory saturation. A system that forgets
nothing has no capacity to generalise.

## 8. Engrams and Ensemble Encoding

The Tonegawa lab (Ramirez, Liu, et al., 2012–2014) used activity-dependent labelling
(TRAP: targeted recombination in active populations) to tag neurons active during a
fear conditioning event with channelrhodopsin. Optogenetic reactivation of this sparse
ensemble — even in a neutral context — was sufficient to retrieve the fear memory
(freezing behaviour), establishing that:

- a memory is physically instantiated in a defined cellular ensemble (the engram), and
- ensemble reactivation is sufficient for recall.

Engram cells are sparse (2–10% of eligible neurons) in dentate gyrus and lateral
amygdala. They are selected partly by intrinsic excitability differences — neurons with
higher CREB activity at time of learning are preferentially recruited. Silent engrams
(accessible only optogenetically, not by natural cue) have been demonstrated in early
Alzheimer's models, indicating that retrieval failure ≠ storage failure.

**Computational role.** Memory storage is content-addressable via partial activation of
the ensemble. A memory is the ensemble; recall is reconstructing the full ensemble from
a subset of active members (CA3 pattern completion). This provides a clean definition
for "memory address."

**Key papers**

- Liu et al. (2012), *Nature* 484
- Ramirez et al. (2013), *Science* 341 (false memory implantation via engram
  manipulation)

## 9. Default Mode Network (DMN) and Offline Cognition

Buckner et al. (2008, *Annals of the NYAS*) synthesised evidence that the DMN — medial
prefrontal cortex, posterior cingulate, angular gyrus, and hippocampal formation — is
active during rest and deactivated during externally-directed tasks. The DMN supports:

- autobiographical memory retrieval
- future simulation / episodic future thinking
- social cognition (mentalising)
- spontaneous mind-wandering

Critically, the hippocampus is a core DMN node. During waking rest, the DMN and
hippocampus co-activate, and this co-activation correlates with spontaneous memory
replay. Evidence from intracranial recordings (Staresina et al., 2023, *Nature
Neuroscience*) shows that ripple-coupled offline reactivation events occur during
waking rest as well as sleep.

**Computational role.** "Dreaming" is not purely sleep-bound. The DMN constitutes a
waking offline processor that runs inference over stored episodic content: simulating
future states, integrating autobiographical memories into self-models, and performing
low-level consolidation-adjacent replay. **Idle periods are processing periods.**

## 10. Spike-Timing Dependent Plasticity (STDP)

Markram et al. (1997, *Science* 275) and Bi & Poo (1998, *Journal of Neuroscience* 18)
established the timing rule: if a presynaptic spike arrives ~1–20 ms before the
postsynaptic neuron fires, the synapse undergoes LTP (long-term potentiation — AMPAR
insertion, increased conductance). If the postsynaptic neuron fires first (causal
inversion), the same synapse undergoes LTD (AMPAR removal, decreased conductance). The
transition between LTP and LTD occurs at ~1–5 ms precision. The LTP window extends to
~50 ms; LTD extends to ~100 ms post timing.

Molecular mechanism: back-propagating action potentials (bAPs) from the soma travel
into dendrites. If a bAP coincides with an EPSP from a recently activated presynaptic
terminal, NMDA receptors (coincidence detectors — require both glutamate binding and
postsynaptic depolarisation to open) admit Ca²⁺, activating kinase cascades (CaMKII for
LTP, phosphatase for LTD) that regulate AMPAR trafficking.

**Computational role.** STDP implements a causal version of Hebbian learning with
millisecond precision. It is the write mechanism at the individual synapse level.
Compressed hippocampal replay falls within STDP windows by design, enabling replay to
drive neocortical weight updates during consolidation.

## 11. Sparse Distributed Representations

Olshausen & Field (1996, *Nature* 381) showed that an algorithm minimising
reconstruction error subject to a sparseness penalty on primary visual cortex (V1)
images learns basis functions resembling V1 simple-cell receptive fields — localised,
oriented, bandpass. This suggests that cortical representations are optimised for
sparse coding of natural signal statistics.

In vivo, ~2–5% of cortical neurons are active at any time in a given region. In the
hippocampal dentate gyrus, sparsity is even more extreme (~2%). Numenta's HTM framework
(Hawkins et al., 2017, *Frontiers in Neural Circuits*) formalises sparse distributed
representations as the computational substrate of cortical inference, noting that SDRs:

- tolerate noise (partial activation still identifies the pattern)
- support exponentially large memory capacity (combinatorial code)
- enable robust pattern separation (overlap between two random 2% SDRs is ~0.04%)
- are metabolically efficient

**Computational role.** Sparsity is not an incidental biological constraint — it is the
representational strategy that simultaneously achieves high capacity, pattern
separation, noise robustness, and energy efficiency. Dense representations degrade all
four properties.

## Implications for Software Architecture

Seven invariants a brain-inspired RAG memory system must respect:

1. **Two-store write architecture (CLS).** New inputs must write to a fast,
   high-fidelity, low-interference store first (hippocampus analog: vector DB with
   sparse, high-dimensional, near-orthogonal indexing). A separate slow store
   (neocortex analog: compressed semantic embeddings, updated by replay) handles
   generalisation. Single-store architectures will either catastrophically overwrite
   old knowledge or fail to learn new information quickly.

2. **Every retrieval is a write (reconsolidation).** Any recall operation must be
   modelled as a potential modification event. Retrieved memory chunks should be
   flagged as labile for a short window post-retrieval, during which they can be
   updated with new context. Immutable retrieval is neurologically incorrect.

3. **Offline processing is mandatory, not optional (replay + SHY).** The system needs
   an offline "dreaming" phase: a process that samples from the episodic store and
   re-presents experiences to the semantic store in compressed form. Without this, the
   episodic store saturates and semantic generalisation never occurs.

4. **Forgetting is a first-class operation (active forgetting).** Implement explicit
   TTL with active deletion, retrieval-induced suppression (when item A is retrieved,
   items that compete on the same cue index are penalised), and a global downscaling
   pass analogous to SHY (lower-salience, lower-access-frequency traces decay).

5. **Sparse, high-dimensional indexing for pattern separation (SDR / DG analog).**
   Memory keys must be sparse and high-dimensional to ensure near-orthogonal
   separation of similar inputs. Dense low-dimensional embeddings — even with cosine
   similarity — collapse similar memories into overlapping representations, causing
   retrieval errors for fine-grained distinctions.

6. **Schema-aware fast-path consolidation (schema integration).** Maintain explicit
   structured schemas (topic models, knowledge graphs, or ontology representations of
   recurring relational patterns). New inputs assessed as schema-consistent should
   bypass the slow consolidation queue and write directly to the semantic store,
   amortising the indexing cost.

7. **Salience and prediction error gate write strength (STDP / replay weighting).**
   Not all events should write equally. Surprising inputs (high prediction error),
   reward-adjacent events, and frequently re-activated traces should receive higher
   weight in consolidation. This requires an explicit salience signal at ingest time,
   analogous to SWR-tagging of waking experiences for overnight replay.
