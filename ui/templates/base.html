Terms

Salience
How much a memory mattered when it was written, 1 to 10: longer and more novel notes score higher.
Decay
Strength that falls with age, to about a third after 30 days. Pinning multiplies it by five. A faded memory ranks lower but still turns up in search.
Labile
Just recalled, so open to revision for a while: new evidence in that window updates the memory instead of piling up beside it.
Reconsolidated
How many times a memory was revised that way after being recalled.
Round
The nightly dream folds memories into summaries: round 1 is an arc of related notes, round 2 a summary of arcs.
Replaced
A newer memory contradicted or updated this one. It stays on disk and out of every session.
DMN
Idle-time maintenance, named after the brain's default mode network: when the machine is quiet it strengthens links between memories recalled together.
